# 候选排序：你选过的说话

**唯一硬规则：选中一次 = 次数 +1，次数多的排前面。** 其它因素只在次数相同时当补充依据。

排序键（依次比较）：

```
1. 选中次数      ← 你按数字键 / 空格接受，都算一次
2. 整串匹配      ← 字数 = 音节数（diyiye 出「第一页」而不是「页」）
3. 上下文        ← 刚打完「因为」，下一个「所以」提前
4. 词频          ← 词库先验（人工收录的现代词 1e7）
```

## 为什么这样才叫「随心输入」

- 你选「为」一次，`wei` 里「为」就排在「微博/微信」前面——哪怕它们词频更高
- 你不选某个候选，它就不会因为「规则认为它更常见」而挤到你头上
- 表情也是候选：没选过就 0 次，排在选过的词后面；选过一次立刻上来

## 怎么调

只改 `src/ipinyin/ime.py` 里 `rank_key()` 的元组顺序即可：

```python
return (-picks, -full, -near, -freq)
#       你选的  整串   上下文  词频
```

想更极端地偏向「你选的」，把 `-picks` 之外的因素都去掉（`return (-picks,)`）。
