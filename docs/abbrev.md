# 简拼（缩写输入）

> `qingkx` → 情况下、`banbl` → 办不了、`rg` → 如果、`jp` → 简拼

## 三种缩写形态

| 形态 | 例子 | 走哪条路 |
|---|---|---|
| 全首字母 | `rg` → 如果、`jp` → 简拼 | 静态表 `initials.marshal`（按词频预排，4.2 万个码） |
| 首音节全拼 + 其余首字母 | `qingkx` → 情况下、`banbl` → 办不了 | **现场组合**（见下） |
| 首字母 + 其余全拼 | `wmen` → 我们 | 静态表 `mixed` |

## 「现场组合」怎么工作

`qingkx` 这种形态查不到现成词——「情况下」根本不在词库里，它是 `情况 + 下` 拼出来的。
所以不能查表，只能**按词组合再排序**：

1. 切段：`qing`（完整音节）+ `k` + `x`（两个首字母）；
2. 首字母按词频展开成音节（`k` → ke/kuai/kan/…/kuang，取前 24 个）；
3. 三条组合路径各取前 8：
   - 词+词：`情况 + 下`
   - 词+词：`办 + 不了`
   - 字+字+字：`办 + 不 + 了`
4. 用字级语言模型排序（`情况下` -12.7 分，`请科学` -19.5 分，一眼分得开）。

## 为什么必须有语言模型

同音组合很多，纯词频排不出来：

```
qingkx → 请科学 / 请客下 / 轻快下 / 情况下
```

词频会选「请科学」（因为「科学」高频），LM 选「情况下」。没有 LM 时这套会退化，
所以 `_lm_score()` 在没挂模型时用词频兜底。

## 一次选中就记住

缩写键和全拼键一起学（见 [personalization.md](personalization.md)）：
`banbl` 第一次可能排第三（`版本来` 在它前面），选中一次后就是第一。

## 边界

- 只展开「首音节全拼 + **两个**首字母」：三段以上（`qkx`）组合爆炸，交给静态表和一次全拼学习。
- 静态简拼表已经有候选时不展开（`rg` → 如果 保持原行为）。
- 打一半的（`nih`）不展开，交给前缀补全——否则每键都要多算几毫秒。
- 展开结果按 `100000 - 名次×100` 编码成词频参与统一排序，学过的词（picks）永远在它前面。
