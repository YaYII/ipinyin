# 个人化是怎么做的

IPinyin 不依赖云端，所有"学习"都发生在你本机：

1. **词频**：每次上屏记一条 `拼音 → 词 → 选中次数 / 展示次数`，
   写到 `~/.local/share/ipinyin/data/user_model.tsv`。
   排序分 = `先验 + 选中次数 + 2 × 命中率`。
2. **词对**：连续两次上屏会合成一个词组（先打「西」再打「大」→ `xidai 西大`），
   同时记录"上一个词 → 这个词"，用于猜下一句。
3. **词组预测**：`user_bigram.tsv` 里的词对会在候选里优先。
4. **简繁**：候选窗同时显示 `简体  繁体`，`Tab` 切换上屏形式，选择会被记住。

这些都是本机文件，不上传；删掉 `~/.local/share/ipinyin/` 就等于恢复出厂。
